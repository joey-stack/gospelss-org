# Requirements Discovery Skill

## Purpose
Translates qualitative stakeholder goals into precise, testable functional and non-functional requirements.

## Workflow
1. **Scope Boundary Check**: Categorize user statements into In-Scope vs. Explicitly Out-of-Scope.
2. **Acceptance Criteria Definition**: Express every feature requirement in Given-When-Then format.
3. **Regulatory Elicitation**: Identify compliance requirements (GDPR, age consent, payment security).
4. **Output Artifacts**: Contributes requirements checklists to `docs/specs/`.
