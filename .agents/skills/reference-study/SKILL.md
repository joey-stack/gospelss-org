# Reference Study Skill

## Purpose
Systematically analyzes visual reference websites (such as Morrow Church, Planfest, REYNA, Karuna, and HOO Festival) to extract structural patterns, visual hierarchy, layout rhythms, and design tokens to create original, superior implementations for GOSPELS.

## Three-Tier Study Methodology
1. **Functional Study (REA)**:
   - Identify user journeys, state transitions, RSVP flows, and interactivity models.
   - Never clone workflows 1:1; adapt them for Gothenburg gospel outreach.
2. **Structural Study (Firecrawl)**:
   - Analyze DOM layout hierarchy, content ordering, heading progression, and responsiveness patterns.
3. **Visual Study (Playwright / Screenshots)**:
   - Capture viewport captures at desktop (1440px) and mobile (390px).
   - Analyze token distributions (spacing scale, typography proportions, elevation shadows).
   - Generate ORIGINAL design tokens preserving the sacred, welcoming, and modern atmosphere.
