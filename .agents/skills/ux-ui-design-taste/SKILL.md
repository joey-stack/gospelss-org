# UX/UI Design Taste & Anti-Slop Skill

## Purpose
Guarantees that every surface, card, hero, and interactive state on `gospelss.org` exudes contemporary sacred excellence, eliminating generic AI design patterns ("slop").

## The Anti-Slop Invariants
1. **No Generic Bootstrap/Tailwind Templates**: Prohibit cookie-cutter 3-column feature cards with centered pastel SVG icons in circles.
2. **No Pure Black / Neon Blue Clichés**: Never use `#000000` or raw browser blue. Use curated Warm Grey (`#F5F5F3` / `#EBEAE5`) and tailored Tech Turquoise (`#14B8A6` / `#0D9488`).
3. **No Unstyled Plain Boxes**: Every card must exhibit deliberate depth: subtle `1px` border strokes (`rgba(0,0,0,0.06)` or `rgba(255,255,255,0.08)`), intentional elevation, and generous internal padding (`1.5rem` to `2.5rem`).
4. **No Cluttered Typography**: Restrict each view to 2 typefaces: Modern Sans (`Hanken Grotesk` / `Inter`) paired with Classic Sacred Serif (`EB Garamond`) for scriptures and pull-quotes.

## Taste Audit Checklist
- **Hierarchy Rhythm**: Does the primary heading command the page? Is there clear visual breathing room between sections (minimum `80px` on desktop)?
- **Micro-Interactions**: Do buttons have subtle lift, smooth transitions (`cubic-bezier(0.16, 1, 0.3, 1)`), and visible focus states?
- **Emotional Alignment**: Does this screen feel *Sacred · Welcoming · Transformative*?
