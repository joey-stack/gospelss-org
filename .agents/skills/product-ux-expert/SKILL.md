# Product UX Expert Skill

## Purpose
Systematically audits and optimizes the user experience across all key user journeys on `gospelss.org`.

## Evaluation Criteria
1. **Frictionless Completion**:
   - Concert RSVPs must require $\le 2$ interactions on mobile (Pill select $\to$ Name/Email $\to$ Instant Confirmation).
   - Giving flows must offer immediate Swedish domestic defaults (Swish QR) with clear recurring upgrade paths.
2. **Cognitive Load & Visual Hierarchy**:
   - One primary action per viewport; secondary paths visually subdued.
   - Form inputs provide real-time validation, clear error messages, and immediate success feedback.
3. **Accessibility & Touch Usability**:
   - Minimum tap target of `48px \times 48px` for all interactive triggers on mobile.
   - No dead-ends: every confirmation page (RSVP, Volunteer, Prayer, Giving) provides logical next steps (e.g. "Add to Calendar", "Explore Worship Music", "Share with a Friend").
