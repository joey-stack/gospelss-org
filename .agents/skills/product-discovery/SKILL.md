# Product Discovery Skill

## Purpose
Guides structured product exploration, competitive intelligence, and target audience needs definition before engineering begins.

## Key Protocols
1. **Audience Persona Profiling**: Identify primary, secondary, and tertiary user archetypes, pain points, and motivations.
2. **Competitive Benchmarking**: Study reference platforms (functional, visual, and operational).
3. **Value Proposition Canvas**: Map core offerings directly to user needs.
4. **Output Artifacts**: Writes discovery summaries to `docs/discovery/`.
