# Slicing into Tracer Bullets Skill

## Purpose
Prevents massive horizontal stalls by deconstructing large systems into thin vertical threads that cut cleanly through all layers (UI, API, Data, Verification).

## Tracer Bullet Methodology
1. **End-to-End Connectivity**: Each slice touches user interface, server action/API, database schema, and test confirmation.
2. **Immediate Executability**: Never leave unverified scaffolding; every slice must run and pass its automated tests before moving to the next.
3. **Sequential Progression**: 
   - Slice 1: Walking Skeleton / Core Layout
   - Slice 2: Primary User Action (e.g. Free RSVP flow)
   - Slice 3: Financial Action (e.g. Kingdom Partner donation)
   - Slice 4: Admin Oversight (e.g. Roster & Prayer inbox)
