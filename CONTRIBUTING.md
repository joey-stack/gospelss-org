# Contributing to GOSPELS (`gospelss.org`)

Welcome! We build with sacred excellence, rigorous TDD, and full transparency.

## Development Workflow
1. **Branch Naming**: Use Conventional branch prefixes:
   - `feat/feature-name`
   - `fix/issue-description`
   - `chore/task-name`
2. **Commit Standard**: Follow Conventional Commits:
   - `feat: add Holy Spirit Worship RSVP endpoint`
   - `fix: resolve Swedish character encoding on event title`
3. **Strict TDD**: Always write failing automated tests before writing production code.
4. **Style Integrity**: Consume CSS variables from `docs/design/BRAND_GUIDELINES.md`. Never introduce unstyled template slop.
